CARA PASANG (WINDOWS)
1. Tutup pengeditan yang belum disimpan di VS Code. Simpan dulu (Ctrl+S).
2. Buka folder C:\xampp\htdocs\dewi-portfolio-multipage\
3. Cadangkan navbar lama terlebih dahulu:
   Copy-Item .\components\navbar.html .\components\navbar-before-internship.html
4. Jika di folder utama sudah ada experience.html (versi lama), cadangkan:
   Copy-Item .\experience.html .\experience-before-internship.html
   (Lompati langkah ini jika file experience.html belum ada.)
5. Extract ZIP ini ke folder terpisah di Downloads.
6. Copy semua FILE dan FOLDER hasil ekstrak ke:
   C:\xampp\htdocs\dewi-portfolio-multipage\
7. Pilih Merge/Gabungkan jika Windows bertanya soal folder.
   Pilih Replace hanya untuk components\navbar.html dan experience.html,
   jika nama file itu sudah ada.
   Jangan menghapus/mengganti seluruh folder assets, css, js, components.
8. Pastikan server lokal tetap berjalan (python -m http.server 8001).
9. Buka http://127.0.0.1:8001/experience.html
10. Tekan Ctrl+Shift+R untuk memuat CSS dan JS terbaru.
