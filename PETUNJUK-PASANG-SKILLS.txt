CARA PASANG DI WINDOWS:
1. Pastikan folder: C:\xampp\htdocs\dewi-portfolio-multipage
2. Backup file components\navbar.html yang sekarang.
3. Ekstrak ZIP ini. COPY ISI ZIP, BUKAN folder ZIP-nya, ke
   C:\xampp\htdocs\dewi-portfolio-multipage\
4. MERGE folder components/css/js; REPLACE hanya components\navbar.html.
5. Jangan hapus file lama atau folder assets. Jangan replace index/about/
   education/projects/experience.html.
6. Pastikan server lokal tetap hidup (python -m http.server 8001).
7. Buka http://127.0.0.1:8001/skills.html lalu Ctrl+Shift+R.
8. Tes menu Keahlian & Tools, tombol ID/EN, dan tampilan HP.
