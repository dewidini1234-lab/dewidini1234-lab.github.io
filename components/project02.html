Sistem Rekapitulasi dan Klasterisasi Aktivitas Media Sosial

Social Media Activity Reporting and Clustering System

Academic Project | Undergraduate Thesis | System Development

21Polsek6Platforms3Clusters
01

Project Overview

Sistem Rekapitulasi dan Klasterisasi Aktivitas Media Sosial merupakan proyek skripsi yang saya rancang dan kembangkan untuk mendukung pengelolaan serta analisis aktivitas media sosial pada 21 Polsek di lingkungan Humas Polres Subang.

Sistem berbasis web ini mengintegrasikan pengelolaan data, rekapitulasi aktivitas, penyajian statistik, dan analisis menggunakan algoritma K-Means. Data yang terkumpul dapat diolah secara terstruktur untuk menghasilkan informasi dan pengelompokan aktivitas media sosial setiap Polsek.

02

Background & Business Problem

Sebelum sistem dikembangkan, proses rekapitulasi aktivitas media sosial masih dilakukan secara manual. Tautan unggahan dikumpulkan melalui WhatsApp, kemudian data direkap dan dihitung menggunakan Excel sebelum disusun menjadi laporan untuk diteruskan kepada Polda.

Proses tersebut menjadi dasar pengembangan sistem terintegrasi yang menghubungkan pengumpulan data, rekapitulasi, dan analisis dalam satu platform. Dengan pendekatan ini, pengelolaan informasi diharapkan menjadi lebih terstruktur dan mendukung proses pemantauan aktivitas media sosial.

03

Fitur Utama Sistem.

Sistem ini mengintegrasikan rekapitulasi aktivitas media sosial, pengolahan data, analisis K-Means, ranking, laporan, serta komunikasi internal untuk mendukung pemantauan aktivitas 21 Polsek di lingkungan Humas Polres Subang.

01↗

Pengelolaan Tautan & Rekapitulasi Aktivitas

Mencatat dan merekap jumlah tautan unggahan dari enam platform media sosial berdasarkan Polsek dan periode pelaporan. Sistem menghitung jumlah URL sebagai data aktivitas tanpa mengambil atau menganalisis isi unggahan.

02▥

Dashboard & Statistik Aktivitas

Menyajikan ringkasan aktivitas, jumlah publikasi, dan statistik data sesuai hak akses pengguna. Admin Polres dapat memantau data lintas Polsek, sedangkan Admin Polsek hanya melihat informasi milik Polseknya.

03◈

Preprocessing & Normalisasi Data

Membentuk dataset bulanan dari rekapitulasi yang telah disetujui, kemudian menerapkan normalisasi Min-Max pada enam variabel platform sebagai persiapan analisis K-Means.

04✧

K-Means Clustering

Mengelompokkan aktivitas media sosial 21 Polsek berdasarkan jumlah publikasi yang telah dinormalisasi. Sistem menampilkan tahapan perhitungan, hasil pengelompokan, dan evaluasi menggunakan Davies-Bouldin Index (DBI).

05★

Ranking & Laporan Kinerja

Menyajikan hasil pemeringkatan dan laporan berdasarkan analisis K-Means. Admin Polres dapat melihat hasil seluruh Polsek, sementara Admin Polsek hanya dapat melihat posisi, hasil analisis, dan membuat laporan untuk Polseknya sendiri.

06◎

Instagram Crawling

Menyediakan modul terpisah untuk mengambil dan menyimpan data postingan akun Instagram utama Polres melalui Instagram Graph API, termasuk informasi interaksi yang tersedia. Data dari modul ini tidak digunakan sebagai input K-Means Polsek.

07✉

Pesan Internal

Memfasilitasi komunikasi dua arah antara Admin Polres dan Admin Polsek melalui ruang percakapan khusus untuk mendukung koordinasi dan pertukaran informasi.

08✳

Pengumuman

Memungkinkan Admin Polres membuat dan menyampaikan pengumuman kepada seluruh pengguna, seluruh Admin Polsek, atau Polsek tertentu. Admin Polsek dapat melihat pengumuman yang ditujukan kepada akun atau satuannya.

09⚙

Manajemen Polsek & Akun Pengguna

Admin Polres memiliki kewenangan sebagai administrator utama untuk mengelola data Polsek dan akun Admin Polsek. Fitur ini mencakup penambahan dan pembaruan data Polsek, pengelolaan status akun, serta pengaturan kata sandi baru. Pengelolaan akun disesuaikan dengan penugasan masing-masing Polsek agar pengguna dapat mengakses informasi sesuai kewenangannya.

04

Dari Rekapitulasi Data Menjadi Analisis Kinerja.

Salah satu bagian utama dari sistem ini adalah implementasi algoritma K-Means untuk mengelompokkan aktivitas media sosial 21 Polsek berdasarkan jumlah publikasi pada enam platform.

Proses analisis menggunakan data rekapitulasi jumlah URL yang telah dicatat dalam sistem. Konten dari tautan tersebut tidak dianalisis; data yang digunakan adalah jumlah aktivitas publikasi berdasarkan platform dan Polsek.

01

Dataset Preparation

Sistem membentuk dataset bulanan dari data rekapitulasi yang telah disetujui. Jumlah publikasi pada enam platform digabungkan berdasarkan masing-masing Polsek sehingga menghasilkan matriks data dengan 21 Polsek dan enam variabel.

02

Min-Max Normalization

Setiap variabel dinormalisasi menggunakan metode Min-Max agar nilai aktivitas dari berbagai platform berada pada skala 0–1 dan dapat dibandingkan dalam proses pengelompokan.

03

K-Means Clustering

Proses klasterisasi menggunakan tiga cluster dengan inisialisasi centroid Farthest-First dan perhitungan Euclidean Distance. Sistem memperbarui centroid serta keanggotaan cluster secara iteratif hingga mencapai kondisi konvergen.

04

Cluster Evaluation

Kualitas hasil pengelompokan dievaluasi menggunakan Davies-Bouldin Index (DBI). Hasil analisis ditampilkan dalam tiga kategori aktivitas, yaitu Kinerja Tinggi, Kinerja Sedang, dan Kinerja Rendah.

05

Ranking & Reporting

Hasil K-Means digunakan untuk menyajikan ranking aktivitas Polsek dan laporan kinerja. Admin Polres dapat melihat hasil seluruh Polsek, sedangkan Admin Polsek hanya dapat mengakses hasil yang berkaitan dengan Polseknya sendiri.

Contoh Hasil Analisis | September 2025

Kinerja Rendah16Polsek
Iterasi2Davies-Bouldin Index (DBI)0,4862

Pada salah satu dataset yang ditampilkan dalam sistem, hasil K-Means membagi 21 Polsek menjadi 2 Polsek berkinerja tinggi, 3 Polsek berkinerja sedang, dan 16 Polsek berkinerja rendah. Proses mencapai konvergensi pada iterasi kedua dengan nilai DBI sekitar 0,4862.

Catatan: Modul Instagram Crawling merupakan fitur terpisah dan tidak digunakan sebagai sumber data dalam proses K-Means ini.
