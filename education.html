FINAL RESEARCH PROJECT

Skripsi

Judul:

Implementasi Algoritma K-Means untuk Klasterisasi Aktivitas Media Sosial Polsek pada Sistem Informasi Berbasis Web di Humas Polres Subang.

Mengembangkan sistem informasi berbasis web untuk mendukung rekapitulasi dan analisis aktivitas media sosial dari 21 Polsek di wilayah Polres Subang. Penelitian ini menerapkan algoritma K-Means untuk mengelompokkan tingkat aktivitas berdasarkan data publikasi yang telah direkapitulasi, menggunakan normalisasi Min-Max serta Davies-Bouldin Index (DBI) untuk mengevaluasi hasil klasterisasi.
