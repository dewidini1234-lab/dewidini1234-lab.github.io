PENTING: CARA PASANG (WINDOWS FILE EXPLORER)
1. Backup dahulu seluruh folder:
   C:\xampp\htdocs\dewi-portfolio-multipage
   ke folder lain dengan Copy + Paste (JANGAN Cut).
2. Di folder website sekarang, rename file lama:
   experience.html  menjadi  experience-projects-old.html
   (jangan dihapus; ini backup halaman proyek lama).
3. Ekstrak ZIP update ini ke folder sementara, misalnya Downloads.
4. Buka hasil ekstrak, SALIN seluruh item di dalamnya:
   about.html, education.html, projects.html, components, css, js
   ke C:\xampp\htdocs\dewi-portfolio-multipage\
5. Jika Windows bertanya, pilih GABUNGKAN folder komponen/css/js,
   dan REPLACE file yang mempunyai nama sama.
   Jangan mengganti folder css/js/components secara keseluruhan.
6. JANGAN menghapus folder assets berisi foto/screenshot.
   File css/experience.css dan js/experience.js lama boleh dibiarkan
   sebagai cadangan, karena halaman baru memakai projects.css/projects.js.
7. Bila server Python pada port 8001 masih hidup, buka:
   http://127.0.0.1:8001/projects.html
   http://127.0.0.1:8001/education.html
   Gunakan Ctrl+Shift+R supaya cache browser diperbarui.
