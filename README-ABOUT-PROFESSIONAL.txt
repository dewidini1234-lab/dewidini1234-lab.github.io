DEWI PORTFOLIO - ABOUT ME PROFESSIONAL CONTENT + FLOATING PHOTO

SCOPE (ONLY THREE FILES):
- about.html: updates About Me text and nine-field Personal Biodata; retains the existing photo, layout, site components, and stylesheet links.
- css/about-story.css: keeps previous color/layout styles and adds a very gentle floating animation to the existing photo frame; motion is disabled for reduced-motion users.
- js/about-story.js: bilingual Indonesian and English content; compatible with the global ID/EN toggle.

THIS PACKAGE DOES NOT MODIFY:
- Navbar or footer
- Home / Education / Projects / Experience / Skills & Tools / Certifications / Contact
- Any photos or other assets

INSTALLATION ON WINDOWS:
1. Back up your existing C:\xampp\htdocs\dewi-portfolio-multipage\about.html and the two About Story CSS/JS files.
2. Extract this ZIP to a temporary folder first.
3. In C:\xampp\htdocs\dewi-portfolio-multipage, replace ONLY:
   about.html
   css\about-story.css
   js\about-story.js
   (Merge css/js directories; never replace the entire directories.)
4. Keep all other files, especially assets/images/foto-about-dewi.jpg, unchanged.
5. Open http://127.0.0.1:8001/about.html and press Ctrl+Shift+R.
6. Check all nine biodata fields, both language options, photo floating, desktop/mobile layout.
